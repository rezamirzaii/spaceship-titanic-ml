## 🌌 About the Project

The goal of this project is to predict whether passengers aboard the **Spaceship Titanic** were transported to an alternate dimension after the ship encountered a spacetime anomaly.

This project is built as a practical **end-to-end machine learning workflow**, from data exploration and preprocessing to model training and Kaggle submission.

---

## 🔬 Project Workflow

* 🧹 Data Cleaning & Preprocessing
* 📊 Exploratory Data Analysis (EDA)
* 🛠️ Feature Engineering
* 🔢 Feature Encoding
* 🤖 Model Training
* 📈 Model Evaluation
* 🏆 Kaggle Submission

---

## 🎯 Problem Type

**Supervised Learning → Binary Classification**

**Target Variable:** `Transported`

* `True` → Passenger was transported
* `False` → Passenger was not transported

**Evaluation Metric:** Accuracy
